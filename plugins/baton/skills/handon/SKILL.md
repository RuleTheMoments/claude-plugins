# handon — 이어받기 (pull)

`session` 스킬의 **§1 이어받기**를 부르는 지름길이다. 아래에서 `H`는 `python3 -I "${CLAUDE_SKILL_DIR}/../../scripts/handoff.py"`다.

1. 인자가 `list`·`ls`·`목록`이면 `/handlist`와 같다 — `H list` 출력을 코드블록으로 보여주고 끝낸다.
2. `Skill` 도구로 `baton:session`을 `<인자>` 인자로 호출하고 **§1 이어받기**를 그대로 따른다. 요점:
   - 대상은 `H pull [인자] --json`으로 정한다. 정하지 못하면 묻는다. 추측해서 열지 않는다.
   - `/handon <이름>`으로 시작했으면 훅이 세션 이름을 이미 붙였다(이번 턴의 `[baton] …` 메시지). 그 메시지가 없거나 키가 다르면 `H title <키>`.
   - 고정층(목표·하지 않을 것·결정·계획)을 먼저 전부 읽는다.
   - `git status`와 마지막 push 이후 커밋만 본다. **`setup`·`verify`는 묻기 전에 실행하지 않는다.**
   - **세션** / 목표 / 마지막으로 증명된 단계 / 막힌 단계 / 다음 행동 하나 / 어긋난 것 / 근거 / 질문 하나 — 이 형태로 짧게 보고한다.
3. 승인 없이 커밋하지 않는다.

사용자와는 한국어로 말한다.
