# handon — 마지막 세션 이어받기

이 스킬은 `session` 스킬의 **§1 이어받기** 모드를 부르는 지름길이다. 아래에서 `H`는 `python3 -I "${CLAUDE_SKILL_DIR}/../../scripts/handoff.py"`다.

1. 인자가 `list`·`ls`·`목록`이면 `/handlist`와 같다 — `H list` 출력을 코드블록으로 보여주고 끝낸다.
2. 프로젝트를 정한다 — `H resolve [인자]`.
   - 인자가 없으면 실행 폴더 기준으로 고른다. 골랐으면 "실행 폴더 기준으로 `<키>`"라고 한 줄 알린다.
   - `match`가 없으면 `H list`를 보여주고 `candidates` 중에서 고르게 한다(없으면 등록할지 묻는다). 추측해서 열지 않는다.
3. 세션 이름을 붙인다. `/handon <이름>`으로 시작했으면 훅이 이미 붙였다(이번 턴의 `[baton] 이 세션 이름을 '<키>'(으)로 붙였다 (세션 <ID 앞 8자>).` 메시지). 그 메시지가 없거나 키가 다르면 `H title <키>`를 실행한다.
4. `Skill` 도구로 `baton:session`를 `<키>` 인자로 호출하고, **§1 이어받기** 절차를 그대로 따른다(§1-0 세션 이름은 3에서 끝났다).
   - 핸드오프 문서를 위험 → 다음 작업 → 함정 순으로 읽고, 함정 목록은 다시 확인하지 않고 믿는다.
   - `setup[]`·`verify[]`와 `git status --short --branch`로 살아있는 상태를 확인한다. 오래 걸리는 것은 백그라운드로.
   - 문서와 실제가 어긋나면 고치기 전에 먼저 보고한다.
   - **세션** / 어디까지 됐나 / 환경 상태 / 어긋난 것 / 다음 작업 / 질문 하나 — 이 형태로 짧게 보고한다. 첫 줄 **세션**은 `<이름> · <세션 ID 앞 8자>`.
5. 미커밋 상태면 커밋할지 묻는다. 승인 없이 커밋하지 않는다.

사용자와는 한국어로 말한다.
