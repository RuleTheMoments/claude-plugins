# handoff — 핸드오프 갱신

이 스킬은 `session` 스킬의 **§2 갱신(`save`)** 모드를 부르는 지름길이다. 아래에서 `H`는 `python3 -I "${CLAUDE_SKILL_DIR}/../../scripts/handoff.py"`다.

1. 인자가 `list`·`ls`·`목록`이면 `/handlist`와 같다 — `H list` 출력을 코드블록으로 보여주고 끝낸다.
2. 프로젝트를 정한다 — `H resolve [인자]`. 인자가 없으면 실행 폴더 기준으로 고르고, 이 세션에서 이미 `/handon <키>`를 했으면 그 키를 쓴다. `match`가 없으면 `H list`를 보여주고 고르게 한다.
3. **먼저 진행 중인 것을 정리한다.**
   - 백그라운드 에이전트·시험·뮤테이션이 돌고 있으면 사용자에게 알리고, 멈출지 끝낼지 따른다.
   - 멈췄다면 소스가 변형된 채 남지 않았는지 확인한다(백업과 `cmp`, `git diff`).
   - 남은 프로세스가 없는지 `ps`로 확인한다.
   - scratchpad에만 있는 산출물(러너 스크립트, 로그, 백업)은 세션이 바뀌면 사라진다. 다음 세션에 필요하면 프로젝트의 gitignore된 곳(예: `.omc/`)으로 옮긴다.
4. `Skill` 도구로 `baton:session`를 `<키> save` 인자로 호출하고, **§2 갱신** 절차를 그대로 따른다.
   - `verify[]`를 실제로 돌린다. 돌리지 못했으면 그 숫자는 "마지막 확인 시점"이라고 적는다.
   - 위험(미커밋·미검증) → 한 일 → 상태 → 다음 작업(막힘 관계) → **함정(이번 세션이 밟은 것 추가)** → 트랜스크립트.
   - 레지스트리는 `H stamp <키>`로 `updated`·`last_session_id`·`transcript_dir`를 맞추고, `one_line`과 바뀐 `warnings`는 직접 고친다.
5. 승인 없이 커밋하지 않는다. 핸드오프 문서가 미커밋이면 그렇다고 보고한다.
6. 끝나면 "재실행해도 됩니다"와 함께 다음 세션 첫 명령을 알려준다 — 실행 폴더(`H current`)와 함께: `cd <실행 폴더> && claude` → `/handon <키>`.

사용자와는 한국어로 말한다.
